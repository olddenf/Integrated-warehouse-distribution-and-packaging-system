## 业务场景测试用例

### 场景1: 订单全流程管理

| 用例编号 | TC-ACC-001 | 用例名称 | 订单全流程管理 |
|---------|-----------|---------|--------------|
| **测试目标** | 验证从订单创建到完成的完整业务流程 |
| **前置条件** | 1. 管理员已登录系统<br>2. 已创建调度员、司机、安装师傅账号 |
| **测试步骤** | 1. 调度员创建订单，填写客户信息、商品信息、配送地址<br>2. 系统自动解析地址获取经纬度<br>3. 系统自动计算配送费用<br>4. 调度员查看订单详情<br>5. 调度员分配配送任务给司机<br>6. 司机登录系统，接收任务<br>7. 司机开始配送任务，系统记录开始时间<br>8. 司机到达配送地点，上传签收照片<br>9. 司机完成任务，系统自动生成安装任务<br>10. 安装师傅登录系统，接收安装任务<br>11. 安装师傅开始安装任务<br>12. 安装师傅完成安装，上传验收照片<br>13. 系统自动完成订单<br>14. 系统自动结算费用 |
| **预期结果** | 1. 订单创建成功，状态为"待派单"<br>2. 地址解析成功，显示经纬度<br>3. 费用计算正确<br>4. 任务分配成功，司机收到通知<br>5. 司机可查看任务详情<br>6. 任务状态更新为"配送中"<br>7. 签收照片上传成功<br>8. 安装任务自动生成<br>9. 安装师傅可查看安装任务<br>10. 安装任务状态更新为"安装中"<br>11. 验收照片上传成功<br>12. 订单状态更新为"已完成"<br>13. 费用结算成功 |
| **优先级** | P0 |
| **测试状态** | 待测试 |

## 测试环境要求

### 硬件环境
- PC端：Windows 10/11 或 macOS
- 移动端：iOS 12+ 或 Android 8+
- 网络：4G/5G或Wi-Fi

### 软件环境
- 浏览器：Chrome 90+、Safari 14+、Firefox 88+
- 服务器：已部署的测试环境

### 测试数据
- 测试用户：至少5个不同角色的用户
- 测试订单：至少10个订单数据
- 测试任务：至少20个任务数据
